# Personal Blog — Gökay UYSAL 🌐

> *"This repo includes my personal blog. It includes information about me, my projects, and ideals."*

## 📜 The Philosophy: The "Web Revival"
In an era dominated by AI-generated templates, bloated web frameworks, and sterile, "too-perfect" UI libraries, I built this website from scratch. It is a deliberate nod to the **Web 1.0 / IndieWeb** movement. 

I wanted to capture the raw, authentic feeling of the early internet. This website isn't about flashy animations; it's about extreme efficiency, fast load times, and true ownership of the digital space. It was coded late at night, on a ThinkPad, reading directly from HTML/CSS documentation books—prioritizing craftsmanship over shortcuts.

## 🛠️ The Tech Stack (Raw & Unplugged)
* **Pure HTML5 & CSS3:** No Bootstrap, no Tailwind, no JavaScript bloat. Just fundamental web standards.
* **RSS Feed Integration:** Built-in RSS (`feed.xml`) to support decentralized, algorithm-free content subscription, honoring the true spirit of the open web.
* **Hosting:** GitHub Pages for lightweight, serverless deployment.

## 🚧 Current Status
Currently, this repository serves as a fully functional infrastructure—a "digital garden" waiting to be planted. While my current focus is heavily directed toward hardware engineering, PCB design, and embedded systems, the foundation remains intact and ready for future writings.
